# Twitch Smart Dock

Плагин OBS для управления Twitch и автоматической смены категории по распознанной игре.

Windows x64 · OBS Studio 32.0.4 и 32.2.2. Python, Lua и отдельный локальный сервис не требуются.

## Скачать

Откройте [Releases](https://github.com/san90091234-hub/twitch-smart-dock/releases) и скачайте `Twitch-Smart-Dock-0.3.4-Windows-x64.zip`. В комплекте: установщик, инструкции, исходники и лицензии.

## Установка

1. Распакуйте архив и закройте OBS.
2. Запустите `Setup.exe` и выберите папку установленного OBS.
3. Откройте OBS → Док-панели → Twitch Smart Dock.
4. Подключите свой Twitch в настройках панели.
5. Для распознавания через Discord нажмите «Вступить на сервер», разрешите публикацию игровой активности и нажмите «Подключить Discord». Выберите способ распознавания и сохраните настройки.
6. Включите автосмену категории. По умолчанию она выключена и ограничена эфиром.

## Статус выпуска

Версия 0.3.4 — предварительная. Проверки загрузки выполнены с библиотеками OBS 32.0.4 и 32.2.2; полный сценарий на чистой Windows ещё не завершён. Другие версии OBS не проверены.

Сборка использует общего Discord-бота и сервер, заданные внутри DLL. Каждый пользователь подключает собственные аккаунты Discord и Twitch. Бот работает, пока открыт OBS.

Исходники отдельно в Git не размещены. Они и лицензии GPL-2.0-or-later / Qt доступны в `Source.zip` внутри комплекта; при передаче сохраняйте весь комплект.
